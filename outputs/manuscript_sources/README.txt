MANUSCRIPT REPRODUCTION

The standalone English HTML manuscript is directly readable without Word or an internet connection. The source text is content.json; all [[reference keys]] are matched to actual Zotero-rendered clusters in ../literature/zotero_citations.json. Numeric citations and the bibliography are generated by Zotero, not manually substituted bibliographic records.

To rebuild the editable Word file, run from the extracted project root:
python outputs/manuscript_sources/build_manuscript.py

Requirements: Python with python-docx and lxml. The builder reads the saved result tables and figures and does not rerun the statistical models. It refuses to build without the real Zotero export. The resulting DOCX requires application-level Zotero Refresh and visual page review before being treated as a final Word deliverable.

To rebuild the standalone HTML after building the DOCX tables:
python outputs/manuscript_sources/build_html.py --root PATH_TO_EXTRACTED_PROJECT

If citation-bearing manuscript text is edited, regenerate the Zotero export first. In zotero_project.js, set the root variable to the actual extracted project path, then run the script through Zotero's Tools > Developer > Run JavaScript as an asynchronous function. Review the script before running it. It creates/reuses only this project's tagged references and collection, formats citations using the included official NLM/Vancouver style, and exports the real item keys and citation data. It does not edit unrelated items or access account credentials.

The included NLM/Vancouver citation-sequence CSL style was retrieved through the official https://www.zotero.org/styles/vancouver endpoint, which redirected to https://www.zotero.org/styles/nlm-citation-sequence on 6 November 2026. Its author attribution and Creative Commons Attribution-ShareAlike 3.0 license are retained in the CSL file.

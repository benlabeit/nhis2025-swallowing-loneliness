# Dysphagia manuscript package

This folder contains the journal-formatted NHIS 2025 manuscript and supporting
files. The statistical estimates are unchanged from the project analyses.

**Title:** Self reported swallowing problems and frequent loneliness in older US adults

| File | Use |
|---|---|
| [NHIS2025_Dysphagia_Master.docx](NHIS2025_Dysphagia_Master.docx) | Authoring master with real, editable Zotero citations in the Dysphagia style |
| [NHIS2025_Dysphagia_Anonymous.docx](NHIS2025_Dysphagia_Anonymous.docx) | Separate manuscript for anonymous review, with citations converted to text |
| [NHIS2025_Dysphagia_Author_Information.docx](NHIS2025_Dysphagia_Author_Information.docx) | Author information and declarations for the submission interface; do not include among anonymous reviewer files |
| [ESM1.pdf](ESM1.pdf) | Online Resource 1: supplementary Figures S1–S3 with captions |
| [ESM2.xlsx](ESM2.xlsx) | Online Resource 2: supplementary results and analysis records, with a contents index and column definitions |
| [figures/](figures/) | Main Figures 1–3 and supplementary artwork in EPS/PDF/PNG/TIFF formats, with captions stored separately |
| [Submission_notes.txt](Submission_notes.txt) | Official-source formatting summary and remaining submission details |

ESM2 contains every file from `extended_tables`: 17 result tables plus the ordinal
model decision and R session record. It also contains five original tables for
severity coefficients and counts, missing responses and participant flow. Numeric
values and original labels are retained; no additional statistics were calculated.
The workbook contains 25 worksheets, including its contents and column-definition
index. The source TSV files remain available elsewhere in the research archive.

The journal artwork uses the same estimates as the [original English
gallery](../figures_en/). Main files are `Fig1`–`Fig3`; supplementary files are
`ESM1_Fig1`–`ESM1_Fig3`. The journal images omit embedded titles and long notes,
which are supplied in [Figure_captions.txt](figures/Figure_captions.txt).

## Version handling

Retain the master with Zotero fields for editing. The anonymous document is a
separate copy; do not replace the authoring master with it. The current journal
instructions contain legacy title-page wording alongside a newer SNAPP notice;
author identities and declarations should be entered in the relevant submission
fields and kept out of reviewer-facing files.

The named journal style and its parent are saved in `../literature/`, together
with the actual Zotero export and rendered bibliography. Builders are in
`../manuscript_sources/`. Rebuilding files does not itself perform native Word
refresh or visual pagination checks. Consult the complete archive's
`VALIDATION_STATUS.txt` for the checks attested for each manuscript version.

This folder is preparation material. No manuscript has been submitted,
editorially reviewed, peer reviewed or accepted. The public research archive
contains author information and is not an anonymous reviewer package.
